# 冲突设计语义

冲突必须推动人物选择或故事事实，不以无原因争吵代替剧情。每条冲突至少记录：
起因、双方目标、阻力、代价、升级触发、阶段结果和遗留影响。

## 三个层面

- 外部：人物、势力、资源、制度或环境之间的对抗；
- 内部：欲望与责任、身份与选择、短期收益与长期代价之间的拉扯；
- 理念：双方都能自洽的价值冲突，最终通过选择与后果体现，不靠长篇说理。

强度应与利益和后果相称。日常摩擦可以和解，重大利益可以妥协或反转，生死冲突
必须有充分累积。避免“一句话不合就终局决战”和反复打败同一个无成长对手。

## 危机链

卷节拍表至少包含三次递增危机。每次危机写成：

```text
当前目标 -> 新阻力 -> 被迫选择 -> 实际代价 -> 新局势
```

递增可以来自敌人能力、资源损失、时间压缩、关系破裂或认知翻转，不必只提升战力。
中段反转应改变策略、关系或对真相的理解；若确实没有，manifest 必须给出合理原因。
卷末危机既要兑现本卷核心承诺，也要留下能落到末章的下一问题。

## 检查

- 起因是否来自已知事实或可验证的新事件；
- 各方是否按自身信息与动机行动，而非为推进剧情突然降智；
- 胜负是否改变资源、关系、风险或信息；
- 解决方式是否符合现有能力、时间和设定；
- 遗留影响是否进入后续章节节点或总纲写回。
