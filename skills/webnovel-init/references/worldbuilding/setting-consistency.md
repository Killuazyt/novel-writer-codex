# Setting consistency gate

Before preview, compare title, genre, target scale, one-line story, core conflict, protagonist flaw, antagonist mirror, world scale, power type, anti-trope, and hard constraints across the selected idea.

Reject contradictions instead of averaging them. Confirm one choice when power rules erase the stated cost, a faction lacks access to its claimed resource, the opening violates a hard constraint, or the antagonist mirror no longer pressures the protagonist's flaw.

After apply, the same confirmed values must agree in state, idea bank, outline/settings, and `MASTER_SETTING`. Existing conflicting JSON is a blocker; authored Markdown is preserved rather than rewritten.
