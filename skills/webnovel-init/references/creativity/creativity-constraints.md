# Creative constraints

## Idea package schema

Each candidate contains a one-line promise, one anti-trope, two or three hard constraints, a protagonist-flaw pressure, an antagonist mirror, and an opening hook. Keep candidates mutually distinct enough for a real decision.

## Hard constraints

A hard constraint changes available actions and has an observable failure consequence. Useful axes include time, memory, identity, resource, relationship, jurisdiction, information, and bodily cost. Avoid decorative prohibitions that never affect a choice.

## Five-dimension score

Score only to clarify tradeoffs: promise clarity, genre delivery, differentiation, sustainable conflict, and execution feasibility. A score does not override the author's choice, and uncertain market claims require current evidence only when the user requested it.
