# Foreshadowing query reference

Use this only to interpret open-loop results; it does not authorize project changes.

| Tier | Typical payoff window | Weight |
|---|---:|---:|
| 核心 | 50-300 chapters | 3.0 |
| 支线 | 30-100 chapters | 2.0 |
| 装饰 | 10-30 chapters | 1.0 |

Urgency is commonly interpreted as `(elapsed chapters / target chapters) * tier weight`. Treat an exceeded target or a long-overdue core loop as critical, and a loop near its target as a warning. The runtime result remains the factual source; this reference only explains labels and narrative implications.

Do not claim that an open loop was resolved unless an accepted commit or current derived projection records that resolution. When only legacy projection data exists, keep the `legacy_projection_fallback` label in the answer.
