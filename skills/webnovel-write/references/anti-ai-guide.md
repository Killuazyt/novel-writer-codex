# 去模板腔写作检查

本参考用于 writer 起草与最终润色。目标是让人物、节奏和细节自然，不是机械替换
词语或追求检测器分数。事实、事件顺序、设定和伏笔始终优先。

## 常见风险

- 每段都走完“起因、经过、结果、感悟”，没有余味；
- 反复使用缓缓、淡淡、微微等万能副词或同一套神态；
- 用“他感到愤怒”等标签解释已经展示过的情绪；
- 对话完整理性、严格轮流，像背景说明或会议纪要；
- 首先/其次/最后、总而言之等列表与总结模板进入正文；
- 句长、段长和信息密度始终均匀；
- 章末安全着陆，把所有冲突一次解决。

## 七层终检

1. 词汇：高风险总结词、枚举词、学术连接词、动作/神态套话逐段检查；命中不等于
   必删，但必须根据语境改写或记录保留理由。
2. 句式：连续三句同构、同义反复、情绪三连和完整四段闭环要拆开。
3. 修饰：抽象评价优先改成动作、结果与代价；避免形容词和程度副词堆叠。
4. 套语：四字套语只在承担叙事功能时保留，不连续堆砌。
5. 对话：每句要有试探、回避、施压、诱导或防御等意图；允许打断、沉默与答非所问。
6. 段落：移动端长短段交替；紧张处短，铺垫处可长但每段必须有新信息。
7. 标点：避免感叹号、省略号连用；逗号过多的长句优先拆分。

## 改写动作

- 情绪标签 -> 生理反应 + 个性化微动作 + 下一决定；
- 抽象结论 -> 事实细节 + 风险或代价；
- 连续说明 -> 动作、对白、停顿和反问混排；
- 背景宣讲对白 -> 带利益与潜台词的对抗；
- 展示后解释 -> 保留展示，删除重复解释；
- 机械章末 -> 留下由本章因果产生的压力或未闭合问题。

default 与 fast 最终必须记录 `anti_ai_force_check=pass` 才能进入 precommit；若仍有
明显模板痕迹则为 fail。minimal 明确跳过深检，不得伪报通过。
