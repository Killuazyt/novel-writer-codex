# 题材钩子与微兑现

每章建议一个后段期待锚点和一至两个微兑现。钩子必须来自本章因果，微兑现必须真实
改变信息、资源、关系、认可或风险。连续三章避免同一组合。

## 电竞

- 钩子：对手换阵、战术泄露、保分或搏命的选择、主力状态异常；
- 兑现：弱点被验证、战术权限变化、队内信任推进、明确赛果或数据变化。

## 直播文

- 钩子：恶意剪辑、回应时机选择、推荐位差值、核心群体动摇；
- 兑现：后台证据、合作窗口、口碑转向、团队分工带来量化提升。

## 克苏鲁或规则恐怖

- 钩子：规则反例、封印提前失效、救人或阻断仪式的选择、记忆缺口；
- 兑现：线索闭环、可执行生存规则、主动决断、关系从怀疑转为共担风险。

使用前检查最近两章钩子与兑现类型；若必须重复，改变对象、代价或结果，并保持时间线
和规则合同一致。
