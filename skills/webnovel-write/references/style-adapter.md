# 题材与文风适配

风格适配只改表达，不改剧情走向、事件顺序、角色行为结果、能力边界或伏笔。默认
字数服从用户和章纲；没有明确目标时沿用项目既有章节长度，不用固定平台字数覆盖它。

## 通用硬要求

- 开头尽早出现行动、风险、强情绪或有效信息；过渡章可放慢，但仍需推进事实；
- 长句与短句、密集信息与留白交替；
- 抽象判断落到动作、反应和代价；
- 关键对白存在意图冲突，角色拥有不同口吻与微动作；
- 章后段保留由因果链产生的期待锚点；
- 最近章节的开场、钩子和情绪曲线避免机械重复。

## 题材权重

- 玄幻/修仙/高武：动作与结果靠前，术语解释后置，升级必须有代价与合法路径；
- 都市/直播/电竞：强化反馈、反应、反制和可量化变化；
- 言情/关系戏：情绪弧线与关系位移清晰，避免只堆感官词；
- 悬疑/规则恐怖：线索可回收，恐惧来自规则与选择代价，不靠形容词堆叠。

最终文本应保持项目既有叙述人称、视角距离和专有名词。任何有意偏离写入 manifest，
由 reviewer 与 precommit 决定是否阻断。
